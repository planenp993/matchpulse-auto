# Архивирани проверки

Тези шест workflow файла описват по-стари развойни етапи. Нямат активни
препратки от текущите проверки и са преместени на 28.10.2026, за да не
се показват като възможни текущи задачи в GitHub Actions. Не се изпълняват
от тази директория. Текущите файлове са `.github/workflows/update.yml` и
`.github/workflows/scout-verify.yml`.

Пазим конфигурациите като история. Не ги връщайте в активната директория,
без да проверите техните клонове, скриптове и предпоставки.
