# MATCHPULSE AUTO | Football-Data Edition

Безплатен уеб анализатор за голови пазари с автоматични CSV обновявания.

## Източници и обхват
- Резултати: Football-Data сезонни CSV файлове за 13 лиги, плюс файлове за NOR, SWE, DNK, SWZ, AUT и POL.
- Програма: https://www.football-data.co.uk/fixtures.csv, когато източникът публикува бъдещи срещи.
- Не използва платен спортен API.
- Евротурнирите не са автоматично покрити.
- Пазарните вероятности са ориентировъчни статистически оценки, не валидирани гаранции.

## Какво е качено
- `docs/index.html`: уеб интерфейс за програма, избор на 5/10/15 мача и история на отборите.
- `scripts/update.py`: автоматичен импорт и обновяване на CSV.
- `.github/workflows/update.yml`: автоматично изпълнение по график и публикуване с GitHub Pages.
- `tests/test_update.py`: проверки на формата на данните.
- `docs/data/history.json`, `fixtures.json`, `status.json`: начални празни хранилища, попълвани при първото успешно изпълнение.

**Важно:** Големият исторически архив от предишния ZIP все още не е качен директно в GitHub. При първото изпълнение системата изгражда началната си база автоматично чрез публичните CSV източници. Обхватът и броят мачове зависят от наличните файлове, затова не е обещан фиксиран брой.

## Еднократна настройка от телефон
1. Отвори: https://github.com/planenp993/matchpulse-auto/settings/pages
2. В `Build and deployment` избери `Source: GitHub Actions`.
3. Отвори: https://github.com/planenp993/matchpulse-auto/actions
4. При нужда стартирай `Matchpulse Auto Football-Data Sync` > `Run workflow`.
5. След успешно изпълнение пробвай: https://planenp993.github.io/matchpulse-auto/

## Какво става автоматично
- При качване в main, при ръчно стартиране и по график сряда и петък (UTC).
- Резултатите се добавят без дублиране, като неуспешните източници се записват като грешки.
- При липса на валидна програма статусът го показва, вместо да измисля мачове.
- В приложението „Историческо демо“ е демонстрация, не текущи предстоящи прогнози.

## Ограничения
- Football-Data обикновено публикува седмични, а не live данни.
- Часовете не са автоматично преобразувани към Europe/Sofia.
- Понастоящем няма интегриран live AI, live коефициенти или автоматични Telegram публикации.
- GitHub Pages публикува JSON данните публично.
- Всичко е насочено към 0 € месечни разходи в рамките на безплатните лимити.
