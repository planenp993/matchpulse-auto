# MATCHPULSE AUTO 4.2 | Football-Data Sync

**Цел:** автоматично обновяваща се статистическа платформа на GitHub Pages с директни Football-Data CSV източници, без платен футболен API.

## Какво е готово и проверено

- 22 326 действителни архивни срещи от 19 първенства (`docs/data/history.json`).
- Скриптът чете оригиналните колони `Div`, `Date`, `HomeTeam`, `AwayTeam`, `FTHG`, `FTAG`, а също и нашия обединен формат.
- Автоматично комбинира наличната история с текущия и миналия сезон за основните лиги и специалните CSV файлове за NOR, SWE, DNK, SWZ, AUT, POL.
- Премахва дублираните мачове; при неуспешни онлайн заявки запазва историята.
- Изтегля `fixtures.csv`, показва незавършени бъдещи срещи от следващите 15 дни, ако източникът действително ги предлага.
- Приложението има програма, анализатор (5/10/15), отборни истории, голови пазари, настройки и AI бриф за копиране.
- **Ново във версия 4.2:** първо автоматично изпълнение при качване в `main`; надеждни отчети за успех/неуспех; проверка на CSV структура; защита от резултати, смесени с бъдещата програма; 12 автоматични теста.

## Еднократно пускане на GitHub: само 3 действия

1. Влез в GitHub и създай **нов празен публичен репозиториум**, например `matchpulse-auto`. Не е нужно да купуваш абонамент.
2. Разархивирай ZIP пакета и качи **съдържанието**, не самата външна папка, в корена на репозитория. Трябва да се виждат `docs/`, `data/`, `scripts/`, `tests/` и **скритата** `.github/workflows/update.yml`. Практично е с GitHub Desktop или git. Основният клон трябва да е `main`.
3. Отвори `Settings → Pages → Build and deployment → Source: GitHub Actions`. При първия push workflow-ът се стартира автоматично. Ако Pages е включен след push, отвори `Actions → Matchpulse Auto Football-Data Sync → Run workflow` веднъж.

След първото успешно изпълнение сайтът ще бъде достъпен на `https://ТВОЯ-АКАУНТ.github.io/matchpulse-auto/` (замени със своите стойности). Проверявай `Actions` за успешно обновяване и `Източници и статус` вътре в приложението за данните и евентуални грешки.

## Автоматизация

- По график **сряда 20:23 UTC и петък 18:23 UTC**, както и при първоначално качване или ръчно Run workflow.
- GitHub Actions може да закъснява и отдалечените CSV файлове могат да отказват заявки. Приложението ясно показва свежестта и грешките вместо да имитира успешно обновяване.
- Ако няма бъдещи мачове в `fixtures.csv`, програмата остава празна. Бутонът **Историческо демо** е само за проверка на логиката и не показва предстоящи залози.
- Часовете от източника не са автоматично преобразувани в Europe/Sofia. Провери ги преди публикуване.
- За Шампионска лига, Лига Европа и Лига на конференциите няма обещан автоматичен календар, защото Football-Data не осигурява надеждна обща програма за тях.
- Това е **статистически**, а не жив AI анализатор. Бутонът AI бриф копира вход за ChatGPT. Няма платен AI API, live коефициенти или автоматично Telegram публикуване.
- GitHub Pages публикува публично историческите JSON данни в `docs/data/`; не качвай тайни или лични данни.

## Локални тестове (по желание)

Изисква само Python 3.10+.

```bash
python -m unittest discover -s tests -v
python scripts/update.py --seed
```

Локално: `START_WINDOWS.bat` или `sh START_MAC_LINUX.sh`, след което отвори `http://localhost:8765`.

## Проверка на проблеми

- Ако първото публикуване не тръгне: включи GitHub Pages, после Actions → Run workflow.
- Ако `Исторически файлове` показва 0/32: онлайн CSV източниците са недостъпни; предварителният архив остава наличен.
- Ако `Програма` е празна: отвори `Източници и статус`, виж `fixtures_feed_status` и провери дали Football-Data е публикувал бъдещи мачове.
- Ако GitHub не показва скритата `.github` папка: качи файловете чрез GitHub Desktop/git или добави workflow файла през уеб интерфейса.
- Ако сайтът е 404, изчакай успешното изпълнение на Actions и потвърди настройката `Source: GitHub Actions`.
