# MATCH LAB X | Публичен GitHub Pages интерфейс

Отделен адаптивен сайт в `docs/match-lab-x/` без промени по кода на Prime Syndicate.

## Достъп

При публикуване на `main/docs` в GitHub Pages стандартният адрес е:
`https://planenp993.github.io/matchpulse-auto/match-lab-x/`

Ако страницата не се отваря, в GitHub Settings → Pages настрой `Deploy from a branch`, `main`, `/docs` (само ако не е вече настроено). Не променяй настройка, която вече хоства Prime Syndicate.

## Данни

- **Football-Data.co.uk**: официално публикувани CSV файлове за сезони 2023/24–2026/27, 18 първенства. Нито един изход не се измисля. Генерират се `data/history/<code>.json` и `data/coverage.json`. При проблем в отделна година се отбелязва честно в provenance, няма фалшиво пълно покритие.
- **Soccerway**: използваме вече работещия публичен read-only календар `../data/fixtures.json`, в който се включват само редове, изрично маркирани със Soccerway. Новият сайт не прави заявки към Soccerway, не използва login или private endpoints.
- **Лиги**: задължително топ 5 + втори лиги (E0 E1 D1 D2 I1 I2 SP1 SP2 F1 F2); допълнително E2 E3 SC0 N1 B1 P1 T1 G1 при проверени ≥500 архивни мача.

## Възможности

Страници: обобщение, филтрирана програма, анализ на мач, изследователски модели и качество на данните. Филтри по лига/дата/отбор, таймзона Europe/Sofia, форма, директни срещи, удари във вратата, експериментални 1X2, над/под, BTTS, точен резултат и опростен условен HT сценарий с 10 000 Монте Карло тегления.

**Публичният модел е базов Poisson ориентир**, изчислен от проверени исторически мачове преди конкретната дата, а не частните четири обучаеми алгоритъма. Това е съзнателна граница: не публикуваме вероятностни дневници от частния `goal-lab-research` без изрично решение. В Research страницата има пряк линк към частния GitHub (изисква потребителят да е вписан).

**Няма доказано финансово предимство, EV/ROI, live odds или minute-by-minute engine.**

## Обновяване

Отделният `.github/workflows/match-lab-x-public.yml` обновява Football-Data UK история веднъж дневно. Soccerway се обновява от съществуващия календарен процес на хранилището. Собствените файлове на публичния сайт са изолирани, без автоматично разпространение на частни резултати.

## Тестване
```bash
python -m unittest discover -s tests -p 'test_match_lab_x_site.py' -v
node scripts/test_match_lab_x_site.cjs
python scripts/build_match_lab_x_site.py
```

`coverage.json` показва текущата дата и действителното покритие.
